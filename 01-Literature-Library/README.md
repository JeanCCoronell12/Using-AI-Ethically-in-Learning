# Literature Library 📚

This directory contains all the peer-reviewed research papers, articles, and studies downloaded from Google Scholar for our research on **Using AI Ethically in Learning**.

## 📌 File Naming Convention

To keep this library organized and easily searchable, please rename all downloaded PDFs before uploading them. Use the following strict format:

`YYYY_AuthorLastName_ShortTitle.pdf`

**Content:**

* `2024_Chanda_Ethical_Implications_of_AI_and_Machine_Learning.pdf`
* `2025_Leong_Ethical_Design_of_AI_for_Education_and_Learning_Systems.pdf`
* `2025_Llerena_Ethics_of_the_Use_of_Artificial_Intelligence_in_Academia_and_Research:.pdf`
* `2025_Slavov_Guidelines-for-Ethical-Use-of-AI-in-Academia_compressed-1.pdf`
* `2026_Shishakly_Academic_ Integrity_and_Students’_Ethical_Use_of_ChatGPT_In_Higher_Education.pdf`
## ⚠️ Important Rules

* **Only upload PDF files** to this folder.
* Do not upload notes, drafts, or text documents here. Any summaries or APA citations belonging to these papers should be placed in the `02-Research-Notes` directory.
